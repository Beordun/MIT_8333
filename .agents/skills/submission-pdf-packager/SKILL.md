# Submission PDF Packager (MIT 8333)

Use this skill at the end of implementation to verify every rubric item before generating the single submission PDF.

## Verification Checklist
1. **12-Section Technical Report (Section F):**
   - [ ] 1. Introduction & Problem Statement
   - [ ] 2. System Objectives
   - [ ] 3. Requirement Analysis
   - [ ] 4. Frontend Technologies Used
   - [ ] 5. Backend Technologies Used
   - [ ] 6. Database Used & Relationships (include ERD)
   - [ ] 7. API Documentation (Swagger/Postman + endpoint table)
   - [ ] 8. Screenshots of Major Interfaces (Login, Register, Student/Staff, Officer, Admin, Tracking Timeline, Swagger)
   - [ ] 9. Testing Evidence (Frontend component tests + Backend API test output)
   - [ ] 10. Deployment Information (Live URL + Cloud DB proof)
   - [ ] 11. Challenges Encountered & Solutions
   - [ ] 12. Conclusion
2. **Codebase Appendix:**
   - [ ] Include all application source files (`prisma/schema.prisma`, `design-tokens.css`, `src/**`, `package.json`), excluding `node_modules/`, `.next/`, and `.env`.
3. **Single PDF Export:**
   - Merge Report + Screenshots + Codebase Appendix into one clean PDF and verify page breaks and readability.
